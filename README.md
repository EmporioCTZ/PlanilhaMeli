# Planilha Meli

Página que lê o PDF de instruções de preparação de envio do Full (Mercado Livre) e monta a planilha do envio:
produto, SKU, código ML, código universal, quantidade e identificação, mais as colunas **Caixas** e **Nome de quem fez**.

- Abra `index.html`, anexe o PDF, preencha caixas e quem fez.
- **Baixar Excel** gera `Envio Full <frete>.xlsx`; **Imprimir** sai em A4 deitado.
- O PDF é lido no navegador (pdf.js); nada é enviado a servidor.
